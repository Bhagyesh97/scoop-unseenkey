# Scoop bucket for Unseenkey

```
scoop bucket add unseenkey https://github.com/Bhagyesh97/scoop-unseenkey
scoop install usk
```

Installs `usk` (the CLI) and `uskd` (the daemon) from the signed release archives
at https://github.com/Bhagyesh97/unseenkey/releases. Manifests update automatically
from each release's `SHA256SUMS`.
